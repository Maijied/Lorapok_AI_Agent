# Professional README Creator Skill

This skill provides guidelines and templates for maintaining enterprise-grade, visually stunning, and complete `README.md` files across projects.

## Key Sections of a Professional README

1. **Header & Branding**:
   - Centered logo / ASCII Banner
   - Tagline summarizing primary capabilities
   - Status badges (CI pipeline, npm version, License, Node.js version, test status)

2. **Executive Summary & Feature Matrix**:
   - Clear value proposition
   - Structured markdown feature matrix with status indicators (`Ready`, `Beta`, `In Progress`)

3. **Multi-Provider Architecture & Setup**:
   - Quick start installation commands (`npm install -g`, `npx`, Docker)
   - API key environment variables (`GEMINI_API_KEY`, `OPENROUTER_API_KEY`, `PERPLEXITY_API_KEY`)

4. **Configuration & CLI Reference**:
   - Environmental variables table with default values and requirements
   - Command reference table listing slash commands, shortcuts, and descriptions

5. **API Specifications**:
   - Endpoint matrix (HTTP Method, Route, Description, Payload Examples)

6. **Quality & Verification**:
   - Test execution commands (`npm test`, Docker tests)
   - Contribution standards and licensing details

## Formatting Rules
- Always keep badges clean and centered.
- Use emojis consistently for section headers (`🌟`, `🚀`, `🎯`, `⚙️`, `💻`, `🌐`, `🧪`, `🤝`, `📄`).
- Use fenced syntax blocks with appropriate language tags (`bash`, `json`, `text`).
