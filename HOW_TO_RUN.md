# 🐛 How to Run Lorapok Agent

> Professional AI coding agent for Node.js, Docker, and Git automation

Lorapok is a **standalone AI coding agent** (v1.0.0) designed for advanced project management and full-stack development. It provides proactive file operations, bash command execution, project analysis, and isolated Docker execution for safe development workflows.

---

## 🎯 Prerequisites

Before running Lorapok, ensure you have the following installed:

| Requirement | Version | Installation |
| :--- | :--- | :--- |
| **Node.js** | ≥18.0.0 | [nodejs.org](https://nodejs.org/) |
| **npm** | ≥8.0.0 | Included with Node.js |
| **Docker** | ≥20.0.0 | [docker.com](https://www.docker.com/) |
| **Docker Compose** | ≥2.0.0 | Included with Docker Desktop |
| **Git** | ≥2.30.0 | [git-scm.com](https://git-scm.com/) |
| **OS** | macOS 10.15+, Linux, Windows 10+ | Any modern system |
