Automate your coding workflows with a focused AI agent.

Lorapok AI is a CLI & API built for developers who need more than chat – it parses actions, runs commands, and integrates with Node.js, Docker, and Git to deliver real automation.

Install via npm View CLI usage

Core Capabilities

Action-Oriented CLI

Parse intents and map them to concrete actions: creating files, running commands, managing Git workflows, and more – all from a single Lorapok CLI.

Node.js Native

Implemented in Node.js with a clean command architecture. Works well with Docker, Express, Jest, and typical backend stacks.

Automation & DevOps

Integrate with CI, scripts, and automation pipelines. Use Lorapok as an assistant for repetitive coding and infrastructure tasks.

Installation

Install Lorapok AI globally via npm:

npm install -g lorapok-ai

Or add it as a project dependency:

npm install lorapok-ai --save-dev

CLI Usage

Launch the interactive CLI:

lorapok-ai cli

Display available commands:

lorapok-ai --help

Run Lorapok from your project directory:

npx lorapok-ai cli
