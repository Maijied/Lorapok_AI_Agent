## 🚀 Project Overview
**Lorapok** is a full-featured AI coding agent powered by the Perplexity API. It provides a CLI interface, a REST API, and deep integration with File and Git management, inspired by Cursor IDE.

## 🏗️ Architecture
The project follows a modular structure:
- **`bin/lorapok.js`**: Executable wrapper for the CLI.
- **`lib/`**: Core logic and internal modules.
  - `agent.js`: Base API integration with Perplexity.
  - `agent-enhanced.js`: Extended agent with file/git awareness.
  - `config.js`: Configuration management (API keys, models).
  - `history.js`: Conversation and command history.
  - `logger.js`: Centralized logging via Winston.
- **`services/`**: Low-level infrastructure services.
  - `FileManager.js`: Secure file operations within project root.
  - `GitManager.js`: High-level Git command wrappers.
- **`tests/`**: Comprehensive Jest test suite (26+ tests).
- **`server.js`**: Express-based REST API server.
- **`index.js`**: CLI entry point and menu system.

4. **Logs**: Check `~/.lorapok/logs/error.log` for debugging.
